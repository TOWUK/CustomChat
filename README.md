# CustomChat
Плагин для сервера Mindustry (ultra optimized)

Отполирован код, самый быстрый, не ресурсоемкий (лол да даже в простое не грузит, а нахуя?) плагин, форматирования чата "НИК: сообщение" белый, чистый чат, только derelict сообщения будут серыми.

Протестировано на сервере с 1 ядром и 300 мб оперативки (боже, задонатьте мне пж), сервер потреблял не более 30 мб (карты, игроки + плагин).

Компилируйте сами, моментально компилируется: `gradle clean jar` или ждите обновления раз в месяц :(
